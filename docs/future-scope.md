# Future Scope

## Current Prototype

The current prototype demonstrates the core concept using:

- One ESP32
- Three virtual classrooms
- Wokwi simulation
- HTML dashboard

The prototype validates the decision-making logic and overall system architecture.

---

## Planned Real-World Deployment

The proposed deployment architecture includes:

- One ESP32 per classroom
- One DHT22 sensor per classroom
- One PIR sensor per classroom
- One Master ESP32
- ESP-NOW communication network

This architecture allows the system to scale to multiple classrooms.

---

## Potential Enhancements

### 1. Air Quality Monitoring

Additional sensors can be added to monitor:

- CO₂ concentration
- Air quality index
- Humidity levels

This would improve environmental awareness inside classrooms.

---

### 2. Energy Analytics

Future versions may include:

- Energy consumption monitoring
- Usage reports
- Efficiency analysis

This can help institutions reduce electricity costs.

---

### 3. Smart Room Allocation

Occupancy information can be used to:

- Identify vacant classrooms
- Assist timetable management
- Improve classroom utilization

---

### 4. Mobile Application

A dedicated mobile application could provide:

- Real-time room status
- Occupancy information
- Notifications and alerts

---

### 5. Cloud Integration

Future deployments may integrate:

- MQTT
- Cloud databases
- Remote monitoring platforms

This would allow access from anywhere with internet connectivity.

---

### 6. Predictive Analytics

Historical classroom data can be analyzed to:

- Predict room usage patterns
- Optimize energy consumption
- Improve campus resource planning

---

## Long-Term Vision

The long-term objective is to transform the system into a scalable Smart Campus platform capable of managing multiple classrooms and providing data-driven infrastructure insights.
